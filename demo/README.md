# ResponseLock Demo Application

Next.js App Router application demonstrating conversion integrity and tracking defects.

## Available Scripts

- `npm run dev`: Start Next.js development server
- `npm run build`: Compile production Next.js build
- `npm run start`: Start production server
- `npm run lint`: Run ESLint checks
- `npm run typecheck`: Run TypeScript compiler check without emit
- `npm run test:unit`: Run Vitest unit tests
- `npm run test:e2e`: Run Playwright E2E tests
- `npm run scan:pii`: Scan for PII and disallowed tracking ID literals
- `npm run check:docs`: Validate shell commands in documentation
- `npm run emit:matrix`: Generate canonical verification matrix
- `npm run verify`: Run the complete 7-stage verification pipeline
